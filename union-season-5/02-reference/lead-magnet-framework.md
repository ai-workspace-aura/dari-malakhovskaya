# Методология создания сильного лид-магнита

## Ключевые принципы

- Лид-магнит — это бесплатное видео (обычно 30-90 мин) для **холодной** аудитории (таргет/ВК)
- Цель: прогреть, создать доверие, довести до следующего шага (анкета/консультация)
- Работает через **историю** и **доказательство результата**, а не через продажу в лоб
- Контент подаётся через **путь клиента** — истории реальных учеников от боли к результату

---

## Структура: 10 обязательных элементов

### 1. Сильный оффер / Заголовок
- Для холодной аудитории: конкретный результат + срок + без предварительных условий
- Формула: "Как [конкретный результат] за [срок] даже если [главное возражение]"
- Примеры:
  - WB: "Как выйти на 300 000 руб/мес с маркетплейса за 3 месяца без опыта"
  - Мастер бровей: "Как записать клиентов на 2 месяца вперёд без соцсетей"

### 2. Актуализация темы
- Объяснить, ПОЧЕМУ эта тема актуальна ПРЯМО СЕЙЧАС
- Привязать к текущим рыночным условиям, трендам, изменениям
- Создать ощущение "сейчас или никогда"
- Пример: "Рынок WB вырос в 3 раза, но конкуренция тоже — те, кто начнёт сейчас, займут нишу до насыщения"

### 3. Раскрытие проблемы
- Объяснить, почему аудитория сама НЕ может решить эту проблему
- Не обвинять, а показать системную причину
- Пример: "Большинство мастеров не знают о правиле сарафана 5×5, поэтому теряют клиентов"

### 4. Пробитие (Probity / Идентификация аудитории)
- Прямое обращение к сегментам целевой аудитории
- "Если ты [ситуация X] — этот видео для тебя, потому что..."
- Даёт зрителю ощущение, что контент создан лично для него
- Перечислить 3-5 ситуаций/портретов ЦА

### 5. Почему старые подходы не работают
- Разоблачить то, что аудитория уже пробовала
- Дифференцироваться от конкурентов, не называя их
- Объяснить, что именно в старых методах неправильно
- Пример: "Все советуют делать рилс каждый день, но это не работает потому что..."

### 6. Раскрытие эксперта
- Регалии, результаты, команда, выручка (если можно — цифры и скрины)
- НЕ просто "я эксперт в X лет", а **доказательства**
- Упомянуть результаты учеников — это усиливает доверие больше личных регалий
- Показать масштаб: сколько людей прошло, какие результаты

### 7. Story-training (История-обучение)
- Рассказать СВОЙ путь: откуда пришёл → какие были проблемы → как нашёл решение → текущие результаты
- Структура зеркалит путь зрителя — он видит себя в прошлом эксперта
- Важно: история должна быть честной и уязвимой, не сказкой об успехе
- Обязательно упомянуть конкретные провалы/ошибки на пути

### 8. Продажа методологии
- Представить свой метод как 3-шаговую формулу/систему
- Каждый шаг — это один блок контента
- Дать методу название (авторская система = уникальное торговое предложение)
- Объяснить логику: почему именно эти 3 шага и именно в таком порядке

### 9. Контент-раскрытие + Кейсы
- По каждому шагу методологии: 3-5 глубоких кейсов (НЕ 10-15 поверхностных)
- Кейс = полная история: ситуация до → что сделали → конкретный результат после
- Формат "Путь клиента": боль → работа → трансформация
- Кейсы из разных сегментов ЦА (охватить все портреты пробития)

### 10. CTA к следующему шагу
- Варианты (от высокой конверсии к низкой):
  1. **Зеркалка TG** — самая высокая конверсия (Direct → личный контакт)
  2. **Анкета с бонусами** — продать анкету как ценность, а не как "заполни форму"
  3. **Консультация** — только если есть ресурс
- CTA должен быть убедительным: "Ты получишь [конкретные бонусы], если заполнишь анкету"

## Чеклист +50% эффективности

### В начале видео
- [ ] CTA за бонус в начале: "Напиши [слово] в директ/комментарии, чтобы получить [бонус]"
- [ ] Мотивация досмотреть до конца: "В конце я дам [ценный бонус], который можно применить сегодня"

### В середине видео
- [ ] Зеркальные TG (Mirror TG) — пригласить подписаться на закрытый Telegram-канал
- [ ] Промежуточные CTA после сильных кейсов

### В конце видео
- [ ] Жёсткая продажа анкеты: перечислить все бонусы, ограничение по времени/количеству
- [ ] Показать, что получат люди, которые заполнят анкету (не те, кто не заполнит)

### Контент-чеклист (ЦА должна узнать себя)
- [ ] Закрыты Топ-5 болей целевой аудитории
- [ ] Закрыты Топ-5 желаний целевой аудитории  
- [ ] Закрыты Топ-5 возражений целевой аудитории

## Технические советы

- **Длина**: 30-90 минут — оптимально для прогрева холодной аудитории
- **Формат кейса**: имя/ник → ситуация до (цифры/детали) → действия → результат (цифры/детали) → эмоциональный момент
- **Зеркалки TG**: отдельные Telegram-каналы под каждый сегмент ЦА или воронку
- **Пробитие**: работает лучше всего, когда перечисляешь конкретные жизненные ситуации, а не абстрактные портреты

## Примеры по нишам

### WB / Маркетплейсы
- Оффер: "300 000 руб/мес с WB за 3 месяца без опыта и больших вложений"
- Пробитие: работает на найме, хочет уйти; мама в декрете; уже попробовал WB но не получилось
- Ключевой кейс: ученик X — зашёл с 0, первые 50к за 2 месяца, 300к к 6-му месяцу

### Бьюти (мастера бровей, ресниц и т.д.)
- Оффер: "Очередь из клиентов на 2 месяца вперёд без постоянных соцсетей"
- Пробитие: работает по знакомым, хочет стабильный поток; снижает цены для конкурентности
- Ключевой кейс: мастер X — делала скидки → внедрила систему → +40 новых клиентов/мес

### Недвижимость (риелторы/инвесторы)
- Оффер: "Как купить инвестиционную квартиру с доходностью 15%+ без личного опыта"
- Пробитие: есть деньги, боится ошибиться; смотрел новостройки, запутался

### IT / Онлайн-доходы
- Оффер: "Как зарабатывать 150 000 руб/мес удалённо без опыта в IT"
- Пробитие: работает оффлайн, хочет в онлайн; уже пробовал фриланс — не вышло

### Отношения / Коучинг
- Оффер: "Как привлечь партнёра своей мечты за 60 дней без насилия над собой"
- Пробитие: в отношениях, но несчастна; одна уже 3+ лет; была измена

## Формула оффера для любой ниши

```
"Как [желаемый конкретный результат] за [реалистичный срок] 
даже если [главное возражение/страх аудитории]"
```

Усилители:
- Добавить цифры везде, где возможно
- Убрать слово "попробуй" — только уверенные утверждения
- Сделать результат максимально конкретным и измеримым
