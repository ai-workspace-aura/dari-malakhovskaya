# Процесс совместного проектирования лид-магнита

## Для каждого нового проекта собрать информацию по этим блокам:

### Блок 1: Ниша и продукт
- Что продаём? (программа, курс, консультация, услуга)
- Цена продукта
- Формат (группа, индивидуально, онлайн/оффлайн)
- Срок до результата

### Блок 2: Целевая аудитория
- Кто целевой клиент? (3-5 конкретных портретов с ситуациями)
- Топ-5 болей (что не даёт спать ночью)
- Топ-5 желаний (чего хотят достичь)
- Топ-5 возражений (почему не покупают)
- Что уже пробовали и почему не сработало

### Блок 3: Экспертность
- Регалии и результаты эксперта
- Количество учеников и их результаты
- История пути (ключевые провалы и прорывы)
- Уникальная методология (как называется, из каких шагов)

### Блок 4: Кейсы (минимум 5)
- Для каждого кейса: ситуация до (цифры) → что конкретно делали → результат после (цифры)
- Кейсы должны покрывать разные портреты ЦА

### Блок 5: Оффер воронки
- Что за бонус в начале видео?
- Что за бонус в конце видео?
- Бонусы за заполнение анкеты (3-5 конкретных)
- Есть ли Зеркалка TG? Что в ней?

---

## Алгоритм работы с Claude

1. **Дать Claude информацию по всем 5 блокам** (можно частями, в разговоре)
2. **Claude составляет оффер** — 3 варианта для выбора
3. **Claude составляет пробитие** — 5 портретов ЦА
4. **Claude составляет структуру контента** по методологии (9 элементов)
5. **Claude составляет скрипт/план видео** по разделам
6. **Claude составляет 14-дневную воронку** с конкретными текстами сообщений
7. **Claude составляет тексты для Зеркалки TG** (первые 10 постов)

## Чеклист готовности лид-магнита к запуску

### Контентный чеклист
- [ ] Сильный оффер с конкретным результатом + сроком + снятием возражения
- [ ] Актуализация темы (почему сейчас)
- [ ] Раскрытие проблемы (почему сами не могут)
- [ ] Пробитие (5 портретов ЦА)
- [ ] Критика старых подходов
- [ ] Раскрытие эксперта (регалии + результаты учеников)
- [ ] Story-training (честная история пути с провалами)
- [ ] Авторская методология (3 шага с названием)
- [ ] 5+ глубоких кейсов по методологии
- [ ] CTA к зеркалке
- [ ] CTA к анкете (с полным списком бонусов)
- [ ] Все Топ-5 болей закрыты
- [ ] Все Топ-5 желаний закрыты
- [ ] Все Топ-5 возражений закрыты

### Технический чеклист
- [ ] Качество звука проверено
- [ ] Качество изображения проверено
- [ ] Ссылка на зеркалку рабочая
- [ ] Ссылка на анкету рабочая
- [ ] Анкета настроена (3-5 вопросов + контакт)
- [ ] Воронка в SendBot настроена
- [ ] UTM-метки на всех ссылках
- [ ] Тест всей воронки прошёл

### Воронка чеклист
- [ ] 14 дней сообщений написаны
- [ ] Сегментация по действиям настроена
- [ ] Ответы на частые возражения готовы
- [ ] Скрипт обработки анкет у отдела продаж есть
