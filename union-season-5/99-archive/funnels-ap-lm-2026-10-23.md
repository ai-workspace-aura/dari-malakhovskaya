# Тексты двух воронок: анкета предзаписи (АП) и лид-магнит (ЛМ)

Версия на момент 23 октября 2026.

Собрано по схемам «АП воронка» и «ЛМ воронка». Это полная версия: основной путь и лестницы дожимов на каждом месте, где человек застревает. Заменяет `funnel-prereg-direct.md` (первые дожимы АП) и `funnel-lead-magnet.md` (старая версия ЛМ-воронки).

## 0. Как читать этот файл

### Две воронки, два этапа

| | АП-воронка | ЛМ-воронка |
|---|---|---|
| Когда | этап 1, сейчас | этап 2, примерно с 25 октября |
| Путь | бот → сайт анкеты → анкета → закрытый канал → ссылка на ЛМ на ютубе | бот → сайт с ЛМ и анкетой (ЛМАП) → анкета → закрытый канал |
| Связь | кто застрял до анкеты, тех переводим на ЛМ-воронку | — |

### Где застревают и как дожимаем

На схемах три красные точки. На каждой своя лестница: идём снизу вверх, пока человек не сделает шаг.

| Точка | АП-воронка | ЛМ-воронка |
|---|---|---|
| **A. застряла в боте, не открыла сайт** | ценность АП (2) → перевод на ЛМ (2) → ажиотаж → прямая регистрация → прямая ссылка на эфир | ценность ЛМ (2) → ценность АП (2) → ажиотаж → прямая регистрация → прямая ссылка на эфир |
| **B. открыла сайт, не заполнила анкету** | ценность АП (2) → перевод на ЛМ (2) → ажиотаж → прямая регистрация → прямая ссылка на эфир | ценность АП (2) → ценность канала (2) → ажиотаж → прямая регистрация → прямая ссылка на эфир |
| **C. заполнила анкету, не зашла в канал** (теряем ~15%) | ценность канала (2) → ЛМ на ютубе → ажиотаж → приглашение на тренинг → прямая ссылка на эфир | ценность канала (2) → тёплое приглашение → ажиотаж → приглашение на тренинг → прямая ссылка на эфир |

### Чередование форматов

Каждая лестница идёт по одному ритму:

**Т** текст → **Г** голосовое (маленькая подпись или без неё) → **Т** текст → **К** кружок + обязательный текст → и снова по кругу.

Для голосовых и кружков даю опору: что Дари говорит, своими словами, без чтения с листа. Длина голосового 30–60 секунд, кружка 20–40 секунд.

### От большего к меньшему

Каждая лестница идёт от большого к маленькому:
1. сначала большой смысл: жизнь, желание, выбор;
2. потом что конкретно она получит: видео, три дня, канал;
3. потом ажиотаж: что уже происходит и сколько нас;
4. в конце самый маленький шаг: одна ссылка, один клик, эфир уже идёт.

Внутри сообщения то же самое: тезис-удар → картинка жизни → что за этим стоит → конкретика → кнопка.

### Тайминг (предложение, подтвердить)

| Шаг лестницы | Когда |
|---|---|
| ценность, дожим 1 | через час |
| ценность, дожим 2 | через час после первого |
| перевод на ЛМ / вторая ценность / ЛМ на ютубе | на следующий день, когда ЛМ-воронка уже запущена |
| второе сообщение этой ступени | через день |
| ажиотаж | через 2–3 дня |
| прямая регистрация | 8 ноября, когда она открывается |
| приглашение на тренинг (точка C) | 14 ноября |
| прямая ссылка на эфир | 15, 16, 17 ноября, за 15–30 минут до 18:00 |

### Регистр

Бот на «ты». Строчные, рваный ритм, столбики, прямой укол, мат в ударной позиции (около 1 на 100 слов). Капс только для анонсов. Подробно в `voice.md`.

Нигде не «бесплатный», только «безоплатный». Цифры для ажиотажа только настоящие: в тексте стоят как `[N]`, команда подставляет факт на день отправки.
