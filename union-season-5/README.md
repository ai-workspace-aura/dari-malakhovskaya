# Союз с собой, 5 сезон: рабочее пространство запуска

Здесь собраны материалы и стратегия запуска 5 сезона терапевтического проекта «Союз с собой» (тема «Либидо жизни», 10 недель, вход через онлайн-тренинг 15–17 ноября 2026). Папка нужна, чтобы команда и Claude работали с одними и теми же источниками.

Для Claude есть отдельный файл [CLAUDE.md](CLAUDE.md): там аудитория, голос Дари и правила работы. README объясняет, что где лежит и как пополнять папку.

## С чего начать

1. Откройте папку `union-season-5` как рабочую: тогда [CLAUDE.md](CLAUDE.md) и скиллы подхватываются автоматически.
2. В CLAUDE.md есть таблица «Что открыть под задачу»: она подсказывает, какие файлы нужны для поста, лид-магнита, бота, продажи или воронки.
3. Скиллы в `.claude/skills/`: `copywriter` для текстов, `marketer` для воронки, `researcher` для исследований.
4. Решения и правки фиксируем в файлах (CLAUDE.md, смысловая карта), а не только в переписке: новый чат видит только папку.

## Как пополнять

- Новые материалы о прошлых сезонах, каналах и аудитории: в `00-materials/`.
- Решения и документы по 5 сезону: в `01-strategy/`.
- Скиллы: в `.claude/skills/<название>/SKILL.md`.
- Фреймворки и чеклисты: в `02-reference/`.
- Результаты работы (тексты, расчёты, исследования): в `03-work/`.
- Устаревшую версию документа: в `99-archive/`, в имя добавляем дату (например `season-5-concept-2026-10-11.docx`).
- Материалы не переписываем и не удаляем.
- Файлы в `03-work/` называем `ГГГГ-ММ-ДД-тема.md`, например `2026-10-20-post-vybor.md`.

## Статусы документов

| Документ | Статус |
|---|---|
| Концепция и продуктовая архитектура | рабочие документы, цены там смешаны (официальная и льготная), брать из CLAUDE.md |
| Смысловая карта | обновлена 12 октября, новые блоки на согласовании у Дари |
| Лид-магнит | рабочий черновик, текстов нет |
| Набросок страницы предзаписи | кнопки не работают, нужно поправить: книга, названия дней из концепции |
| Сводки по аудитории из сторис | гипотезы, не исследование |

## Что в материалах персональное

В Telegram-экспортах, транскрибациях и сторис есть имена и истории участниц, скриншоты переписок и фото. Для публикации чьих-либо историй нужно отдельное согласие. Не отправляйте эти папки третьим лицам без необходимости.

## Чего пока нет

Стратегии по этапам, выгрузки постов Instagram (есть только сторис), конкурентного анализа и данных анкеты предзаписи. Ключевые даты запуска (кроме тренинга 15–17 ноября) тоже ещё не заданы.
